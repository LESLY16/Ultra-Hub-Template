# UltraThemeHub

UltraThemeHub is a responsive, browser-based gallery of website template concepts. Visitors can preview 12 template designs and download a generated, standalone HTML starter page customized with a brand name, accent color, pricing tiers, and feature label.

## Features

- 12 template preview cards for business, SaaS, creative portfolio, ecommerce, blog, restaurant, fitness, real estate, healthcare, events, nonprofit, and admin dashboard themes.
- Responsive gallery layout with dynamically scaled previews.
- Modal previews and an in-page developer documentation dialog.
- Client-side template generation and download as a single HTML file; no server or build process is required.
- Copy buttons for the bank details shown in the donation section.
- Responsive styling for desktop and mobile screens.

> The downloadable pages are generated by `script.js` from a shared starter layout with the selected template's title, brand, color, prices, and feature subtitle. They are not separate, fully implemented versions of every preview design. Review and customize the generated page before using it in production.

## Run locally

There is no package installation or compilation step. Clone or download the repository, then open `index.html` in a modern browser.

For a local web server, run this from the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Use the gallery

1. Open the page in a browser.
2. Select **Preview** on a card to view its design mockup.
3. Select **Download** to save a generated HTML starter page.
4. Open the downloaded file and edit its content, links, styles, and form behavior as needed.

The preview modal is intentionally non-interactive. The generated contact form currently displays a confirmation alert; it does not submit data to a backend or send email.

## Customize

- **Gallery content and template cards:** edit `index.html`.
- **Colors, layout, and responsive styles:** edit the CSS variables and rules in `style.css`.
- **Preview behavior and downloaded-page markup:** edit `script.js`, especially `openPreview()` and `downloadFullTemplate()`.
- **Add a gallery template:** add a card in `index.html` with a unique preview element ID, then connect its Preview and Download buttons to the corresponding JavaScript functions. Add any required styles in `style.css`.

The stylesheet imports the Plus Jakarta Sans font from Google Fonts. A system sans-serif fallback is used if the external font is unavailable.

## Important before publishing

The donation section in `index.html` contains sample bank information (including the account holder “Dummy Human” and bank “MoneyFull Bank”). Replace it with verified details or remove the section before deploying the site. Do not rely on these details for real payments.
