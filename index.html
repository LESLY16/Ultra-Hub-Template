Everything you need to integrate, customize, and extend UltraThemeHub templates.

Architecture Overview

UltraThemeHub operates as a zero-dependency static distribution engine. Template previews are micro-rendered into 16:9 responsive thumbnails using CSS scale transformations. Download operations dynamically generate standalone, un-watermarked HTML files via JavaScript Blob URLs.

API Function Reference

  • openPreview(templateId) — Injects the watermarked template into the modal preview overlay with interactive triggers disabled.
  • closePreview() — Dismisses the modal overlay and purges cached DOM preview elements.
  • openDocsModal() — Opens this documentation pop-up window.
  • copyText(elementId) — Copies direct account transfer details to the user clipboard using Navigator Clipboard APIs.
  • downloadFullTemplate(...) — Generates a fully responsive HTML template file with custom color palettes, numerical pricing tiers, and contact forms.

Custom Template Integration

To register a new template card inside the grid, use the standard .card structural boilerplate:

<div class="card">
  <div class="card-preview-wrapper">
    <div class="card-preview-frame">
      <div class="watermarked-template" id="tmpl-custom">
        <!-- Mini UI Component Layout -->
      </div>
    </div>
  </div>
  <div class="card-body">
    <h2 class="card-title">Template Title</h2>
    <button onclick="downloadFullTemplate('Title', 'Brand', '#hex', 10, 20, 30, 'Category')">Download</button>
  </div>
</div>
